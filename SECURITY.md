# Security policy

Mobile API Studio handles local network traffic, development certificate material, device proxy settings, and optional secrets. The source is open for review, but the `0.0.1` desktop build is a preview and has not completed the [final validation checklist](docs/FINAL_VALIDATION.md). No production release or support window is promised yet.

Please report suspected vulnerabilities privately through this repository's **Security → Report a vulnerability** flow. Do not put exploit details, credentials, certificate private keys, or captured private traffic in a public issue. If private reporting is unavailable, contact the maintainer through the [DagerottDev GitHub profile](https://github.com/DagerottDev) to arrange a private channel before sharing details.

Include the affected commit or build, macOS/runtime versions, reproduction steps using non-sensitive sample data, expected and observed behavior, and the security impact. See [Security and privacy](docs/SECURITY_AND_PRIVACY.md) for the current design boundaries.
